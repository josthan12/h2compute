# Architecture Decision Records

Record decisions that affect architecture, cost, privacy, security or maintenance.

Suggested first records:
- `runner-provider.md` — hosted runner, current terms/free quota, privacy, limits, fallback.
- `hosting-provider.md` — free-tier terms, public beta eligibility, donation compatibility.
- `exercise-interface.md` — stdin/stdout versus function-based evaluation.
- `content-mapping.md` — how official syllabus outcomes are represented in frontmatter.

Use: Context → Decision → Alternatives → Trade-offs → Date checked → Revisit trigger.
