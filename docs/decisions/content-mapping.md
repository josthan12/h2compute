# Content mapping proposal

**Date checked:** 12 October 2026  
**Status:** Source verified; editorial sequence awaiting approval.

Use the official 2026 syllabus's numeric learning outcome references as strings, with syllabus year 2026 and printed PDF page numbers. Internal lesson IDs must not be presented as official identifiers. Every quiz/exercise maps to the precise subset it assesses.

The current [SEAB index](https://www.seab.gov.sg/gce-a-level/a-level-syllabuses-examined-for-school-candidates-2026/) links the [9569 PDF](https://isomer-user-content.by.gov.sg/334/cd7aef2f-eef7-4e5a-bebe-2339b214db42/9569_y26_sy.pdf). The older planning-document URLs were unavailable. The [Phase 1 review](../phase-1-feasibility.md) contains the verified reference table, checksum, exclusions and coverage gaps.

Only Python programming, algorithms/data structures and relational databases/SQL belong to this MVP. Broader or compound outcomes are marked partial when only their selected portions are taught. Proposed mappings are planned coverage, not published coverage. NoSQL and other omitted areas remain visible gaps without entering the MVP.

First bounded topic proposed: Python control flow. Content must be original, reviewed and tested after implementation approval. Revisit on a syllabus update or when a lesson's assessed scope changes.
